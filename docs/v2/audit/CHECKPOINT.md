### 3.3 MACRO-A（位階 → 目標%）— 已用本機凍結快照實跑回測

**現況：目標% 三個交易日就跳一次**（台股，4,783 日 / 19.58 年，跑 production 路徑）：

| | 次數/年 |
|---|---|
| 位階翻轉 | 65.6 |
| **目標%變動** | **73.8** |

照著交易：週轉 2,048 pp/年、成本 **9.65% NAV/年**。
根因是階梯函數——目標只有 {90, 60, 40, 10} 四個值，健康分在門檻邊抖一下就跳 30pp。

**反直覺發現（推翻了總管派工單的假設）**：

| 防抖做法 | 翻轉/年 |
|---|---|
| 現況 | 15.6 |
| 雙門檻 δ=7 | 10.5（只降 33%） |
| **連續 3 次確認 K=3** | **4.0**（降 74%） |

→ **做事的是「連續確認」與「覆核頻率」，不是門檻寬窄。**
覆核頻率是更大的槓桿：逐日 85.9 → 月頻 6.6 次/年。

**提案算式（台股，整體持股水位）**：
```
             ⎧ (20/35)·h            0 ≤ h < 35
w_post(h) =  ⎨ 20 + 2·(h − 35)     35 ≤ h < 50
             ⎩ h                   50 ≤ h ≤ 100

w = min( w_post(h), 天花板C, 20·1[防禦旗標] )
```
三個錨點 `w(35)=20` / `w(50)=50` / `w(100)=100` 皆來自既有 SSOT。

**再平衡**：`d = 實際% − 目標%`，`|d| > B` 才動，**回補到帶緣不是目標點**（實測差 5 倍成本）。
B = 10pp（台股整體水位、基金核衛，後者沿用 `PORTFOLIO_CORE_SAT_TOLERANCE_PP`）；逐檔 5pp。

**綜合效果**：73.8 → 5.5 次/年，成本 9.65% → 0.34% NAV/年。

⚠️ **MACRO-A 自列 12 條未查證事項**，最該打折的：
**回測有 lookahead 未修**（M1B/M2 腿約 7 天前視；基金月頻腿約 1 個月）
→ **CAGR/MDD 不得當可交易績效讀**，只有「翻轉頻率」與「跨參數比較」成立。
另：重建的 health ≠ production health（廣度腿判定有 20.25% 的日子相反）；
基金重建只有 6~7 條腿（完整約 14），**水位不可引用、只有翻轉頻率可引用**。
