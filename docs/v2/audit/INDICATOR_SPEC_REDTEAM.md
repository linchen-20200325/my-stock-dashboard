## 打不倒的（據實記錄「試過什麼」）

- **A1｜R-2 涵蓋門檻的浮點漂移**：試過 ETF 7 維權重的全部 127 個子集，以及 `{.15,.15,.12,.08}` 的 24 種相加順序，**0 命中** —— 找不到「同組因子因相加順序跨越門檻」的反例。
- **A1｜§1-b 禁令 1（缺值不得用 `0`）**：實跑 `0.0`／`-0.0`／`False`／`Decimal('0')`／`int 0` 五種零載體，`is None` 全 False —— 禁令在**載體層面**確實擋住了，**打不倒**（漏洞出在 R-3，已列 A1-11）。
- **A2｜§4-a「不適用與缺漏一律不進分母」這個決策本身**：試過 (1) 讓缺漏留分母當 0 分、(2) 留分母給中性分 → 兩者都撞 §4-c；(3) 找 repo 內「缺漏留分母」的既有正解當反證 → 三處實作**全都**移出分母。**找不到反例**（§4 在這一點上是追認現況）。
- **A2｜§4-b 的「有效滿分 == 0」那半**：試過全缺、滿分 0 的因子、負滿分三種輸入，都沒能讓它產生錯誤結論。**找不到反例。**
