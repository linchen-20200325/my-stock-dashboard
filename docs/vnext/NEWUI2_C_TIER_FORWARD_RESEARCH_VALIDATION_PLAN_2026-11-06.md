## 研究分三階段（最小成本）
1. **R0 唯讀盤點**：先查 repo 已有資料/公式/歷史研究與測試；做 Source→Canonical→Evidence 追溯和 Missing Matrix。三種路線先比較（直接用既有確定性資料、核准來源拓展、資料不足暫停），優先採最快且不失真路線。**無新來源、無寫入、無模型研究幻覺**。
2. **R1 影子研究（Research / Shadow）**：只用已核准且 time-safe 的資料測試假說，確認有效樣本期、forward test / OOS、與 baseline 相比是否真的有增量價值；保留研究日志、反證、失敗案例、lookahead/存活者偏差檢查。
3. **R2 準入裁示**：評估有無可復現提升、資料取得/長期成本、模型/Token 適用性與正式風控衝突；若不足，維持 Research，**不代表否決研究價值**。若值得導入，另案 Source Gate、Domain formula Gate、Risk Cap / System Action Gate 與完整 QA，再交 Claude Code 分批施工。

## OneBrain 的定位
- 研究證據可作 **approved research context**，需有研究期/版本/來源和結論不確定性；研究假說不能冒充即時客觀市場數據。
- OneBrain 只能接收已經由資料層提供、治理核准的證據；不得為證明研究假設自行搜尋、呼叫外部來源，或把不完整的資料補成 0/中性。
- 分頁與總結 OneBrain 都用白話文說明「為何有價值、支持/反對證據、尚未驗證」；不得自動把研究方向轉成正式買賣指令。

## 目前與後續交接
- C 級是**持續研究待辦**，不是 UI2 首批生產上線範圍，也不是永久禁止；不得因 UI 簡化而刪除歷史研究來源。
