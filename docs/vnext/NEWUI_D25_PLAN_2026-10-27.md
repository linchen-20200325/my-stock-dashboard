| 評準 | AB-0 | RS-1 | NAV-1（對照） |

### 8.2 導覽殼替換（NAV-1）開工前須先處理的風險
1. **Boot incident 同模組**：`shared/ia_nav.py`、`app.py` 約 287 行 import、`src/ui/views/shell_nav.py` 是事故涉及範圍；root cause 未確認，批次規格不得假設「stale module」為根因，也不得假設「已修好」。
2. **PR 必過 boot import smoke**，且需涵蓋新增模組／新 import 名稱（INFERENCE：現守衛的靜態契約檢查 `app.py` 所 import 的名稱，新增導覽模組時需同步擴充）。
3. **客戶實機點驗**：沙箱無法重現 Cloud 啟動行為；完工報告須標「限制：Cloud 行為未於沙箱實測」。
4. **舊 UI 與預設入口不變**：舊 UI Removal Gate 仍有效；新四頁未完成實機驗收前不得刪舊 UI；D2 殼保留至替代完成（替代以獨立 PR）。
5. **一次一檔寫入**（PROCESS.md §3），避免同時改三個事故範圍檔；可回滾（單 PR 可 revert）。
