上圖「⚡」**不是**新建 System Action；W-10 聚合器未備前只能沿用已核准的現有關鍵警示／配置衝突（並標明其非正式 System Action），或 `⬜ 尚未提供`，不推造計數。缺值 UI 示意不是市場現況。

**高度關鍵**：既有 📊 手機 unavailable 場景首屏餘裕曾量得 162.5px，距 ≥160px 底線只有 2.5px；此稿不承諾任何新增頁首高度。凡改上半屏、字體、共同 CSS、卡片 padding，必須跑量測與 mutation guard。

## 4. 圖表資料與來源 Gate

| 圖／區 | 源與取值前提 | SPEC／比較方式 | 無資料處理 |
|---|---|---|---|
| 台股 Primary | 正式可追溯台股歷史序列；MA 僅參考線、沿既有規則 | 同標的、同日期與單位；來源／as_of | 不得以單筆加權指數畫歷史曲線 |
| 核心卡 | 正式台股、VIX、US10Y、利差、DXY、PMI／景氣 | 每卡獨立頻率／發布時間／資料日 | 缺欄不轉成 0 或正常 |
| 國際 small multiples | 各市場正式序列，原始單位與交易日對齊 | **各小圖獨立刻度**；不混價格／殖利率／匯率於同軸 | 有哪些才畫哪些；缺的標來源狀態 |
| VIX／門檻 | 正式 VIX 序列與既有 threshold SSOT | 不新增顏色門檻或風險規則 | 無法核對門檻時只呈資料，不畫帶 |
| Macro mini | 已核准來源與有效更新頻率 | 區分 monthly / daily；資料 as_of ≠ fetched_at | 不用今日冒充資料日 |
| 圖 C EPS×PE | 已核准研究資料／明確時間口徑與尚未核准事項 | 標 **Research／未啟用**；不連到 Risk Cap 或 System Action | 欄位不夠就保持研究槽 |

狀態三軸依正式 Contract（Field State、Capability、Judgement），失效不能被說成安全；OneBrain 必須取得完整 Decision Digest（而不是使用者可見的六張卡或圖表 Top-N）。
