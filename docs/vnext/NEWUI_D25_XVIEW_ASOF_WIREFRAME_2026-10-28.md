## §2 Level 1 共同格式（全部位置同一把尺）

**一個價格 ＝ 數字＋下面一行小字。** 小字只放兩件事：資料時間、來源。

```
現價　123.45
　　　2026-10-28 收盤｜Yahoo
```

**狀態字樣表（全部是文字，顏色只是輔助）**

| 情況 | 小字寫法 | 說明 |
|---|---|---|
| 正常、收盤 | `2026-10-28 收盤｜Yahoo` | 最後一根 K 的日期＝預期最新交易日，且已過收盤時點 |
| 正常、盤中 | `2026-10-28 13:30 盤中｜Yahoo` | 只有在能確定是當日未收盤 K 時才寫「盤中」＋時間 |
| 盤中／收盤無法確定 | `2026-10-28｜Yahoo（盤中或收盤未確認）` | ⛔ 不猜「收盤」（yfinance 盤中行為**未驗**，報告 §1.3） |
| 非最新（stale） | `⚠ 非最新（上次成功 10/27 收盤）｜Yahoo` | 最後一根早於預期最新交易日（`expected_latest_trading_day()`） |
| 備援來源（fallback） | `2026-10-27 收盤｜備援來源：FinMind` | 主源失敗、換源成功；FinMind 盤中只到前一交易日（INFERENCE） |
| 有補值（ffill） | `⚠ 含補值日（10/28 沿用 10/27）｜Yahoo` | P-ETF `close_ffilled_days` 命中最後一根時 |
| 時間／來源拿不到 | `資料時間：⬜ 未提供` | ⛔ 不用「今天」代替、不留白讓人以為是最新 |

規則：
1. **⚠ 字樣與文字標籤一定要有**；顏色（例如灰字、黃底）可加可不加，但拿掉顏色後意思不能變。
2. 小字**一行內結束**（手機 390px 寬可換行，但不新增第二層區塊）。
3. 完整說明（還原口徑、取數順序、預期交易日怎麼算、快取多久）**只放「🔍 查看依據」展開**（§5），不上 Level 1。

## §5 「🔍 查看依據」展開裡放什麼（Level 2，完整 methodology）

沿用既有「查看依據」區塊（線框已有：使用的資料／資料日期／規則／missing／confidence／AI 是否參與），**只在「使用的資料」與「資料日期」兩格補價格說明**，不新增區塊：

- 價格來源鏈：個股＝Yahoo（還原）→ FinMind（原始價，試還原）→ Yahoo（預設參數）；ETF＝Yahoo（還原）。本次實際用的是哪一腿。
- 還原口徑：還原／原始（依實際成功的那一腿）。
- 資料時間：最後一根 K 的日期；預期最新交易日；兩者相差幾個交易日。
- 是否含補值日（ffill）與日期。
- 快取：這份價格最多可能是多久前抓的（TTL，取自 `shared/ttls.py`；不寫死在畫面文字裡）。
