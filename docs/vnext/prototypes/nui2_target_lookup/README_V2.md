## V1 → V2 逐狀態差異
| 狀態 | V1 | V2 |
|---|---|---|
| idle／9006／9099／市場精選 | 見 V1 | 僅 title 文字、展開區標籤不同，其餘同 |
| 9001 OK | 🟢 資料日在規則內 chip＋「…不是買賣訊號」句＋規則展開 | 無 chip、無 OK 詳述；資料日＋六欄示範值；展開僅一行 `資料日 ｜ 來源` |
| 9002 STALE | ⚠ 過期 9 天＋規則段落 | ⚠ 過期 9 天（沿用既有格式；9 天是示範夾具本身，不引用規則）；展開僅一行 |
| 9003 部分缺值 | 🟡 部分欄位未取得＋「3／6 欄有值」 | 無總結 chip、無欄數；三欄示範值＋三欄逐欄「⬜ 資料未取得／資料未備」 |
| 9004 不可用 | 🔴 來源目前不可用＋「原因類別：來源逾時（示範）」 | 🔴 來源目前不可用（僅此）；展開一行，資料日顯示「⬜ 資料日未提供」 |
| 9005 日期不可信 | 🔴 資料日期不可信 chip＋內文＋展開含「來源有回應，但資料日晚於基準日」「資料日期不可信，不顯示」 | 僅紅框「資料日期不可信，暫時無法顯示」；全頁（含展開）無任何日期；展開一行資料日為「⬜ 資料日未提供」 |

**移除理由句的原因**：「來源逾時」「來源有回應，但資料日晚於基準日」「資料日期不可信，不顯示」等理由類別需要源頭有可稽核訊號（#7003017605 (b)）；尚無真實來源契約，V2 不呈現（V1 保留不動供對照）。
