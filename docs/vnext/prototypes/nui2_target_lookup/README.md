# NUI2 標的「即時查一檔」視覺原型（隔離・離線・FAKE）

> **這是示範，不批准正式施工。** Visual Gate 待客戶核准。授權：#1199 comment 7000042502（第一階段）；DEC-203。

## 用法
雙擊 `index.html`（單檔、內嵌 CSS／JS、零外部資源、零網路）。手機 390×844、桌面 1440×900 皆可操作。與 App 完全隔離：未改 `app.py`／`app_ui2.py`／`src/ui2/**`／`src/services/ui2/**`／`shared/ui2_contract/**`，無任何程式引用本檔。

## 字句來源
- **逐字重用**（`shared/ui2_contract/text.py`、`real_canonical.py`）：⬜ 資料未取得／資料未備／資料日未提供、⚠ 過期 N 天、🔴 來源目前不可用、⬜ 尚未評估／尚未載入、請輸入代碼（名稱搜尋尚未提供）、加入觀察（尚未提供）及原因、隔離說明、精選尚未開放…、「資料日在規則內只表示…不是買賣訊號」（出自 2026-11-18 新鮮度設計文件，非 text.py）。測試對照 text.py。
- **任務指定（授權）**：頂部橫幅「示範原型・FAKE 資料，不是市場資料」、「示範值」、「資料日期不可信，暫時無法顯示」。
- **PROPOSED・未核准（UI 上皆有小標）新字句清單**：🟢 資料日在規則內（chip；字樣出自設計文件）／示範範例（點選即查）／示範：資料齊全｜資料過期｜部分缺值｜來源不可用｜日期不可信｜尚未評估｜查無此標的／輸入代碼或點選左側示範範例後按「查詢」／請先輸入代碼／查無此標的／示範原型只收 9001~9006／原因類別：來源逾時（示範）／展開：資料日／來源／規則／示範來源／示範規則：資料日距示範基準日 2026-11-19 不超過 3 天視為在規則內，超過視為過期／清除查詢結果／請先切換到「即時查一檔」。

## 最小正式接線差額與 Gate（⛔ 皆未授權）
差額：查詢服務（代碼→標的資訊 VM）、真實資料源、六欄 FieldVM 填值、查無／錯誤分類、session 隔離。≤3 Gate：
1. **真資料權利／PIT／Schema**：來源授權、資料日（PIT）規則與 Schema 契約。
2. **查詢服務契約**：輸入正規化、查無／來源失敗／日期不可信的分類與字樣核准。
3. **OneBrain 接線**：與六欄語意、位階（市場環境）一致性。
