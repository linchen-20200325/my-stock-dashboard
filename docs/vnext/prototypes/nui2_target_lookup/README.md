# NUI2 標的「即時查一檔」視覺原型（隔離・離線・FAKE）

> **這是示範，不批准正式施工。** Visual Gate 待客戶核准。授權：#1199 comment 7000042502（第一階段）；DEC-203（含修正輪補註）。

## 用法
雙擊 `index.html`（單檔、內嵌 CSS／JS、零外部資源、零網路）。手機 390×844、桌面 1440×900 皆可操作。與 App 完全隔離：未改 `app.py`／`app_ui2.py`／`src/ui2/**`／`src/services/ui2/**`／`shared/ui2_contract/**`，無任何程式引用本檔。所有畫面字串集中在檔內 `#strings` 登錄表（每條標 `reuse`／`auth`／`proposed`／`meta`），由 `S()` 渲染，**proposed 一律自動附可見「PROPOSED・未核准」小標**。

## 切換
切到「市場精選」：搜尋 `aria-disabled`＋原因（「尚未開放查詢」＋PROPOSED 提示），顯示「精選尚未開放…」；切回保留上次查詢。手機版面順序：模式／搜尋 → **結果** → 示範範例（查詢後結果在第一屏）；桌機：左欄控制＋範例、右欄結果。

## 規則出處與核准狀態
- 「資料日距示範基準日不超過 **7** 天視為在規則內」：數值對映 `shared/staleness.py` `STALE_DAYS_DAILY = 7`（日頻；repo 既有常數）。**核准狀態：該常數為既有實作；套用於 🎯 即時查一檔的呈現未經核准＝PROPOSED。**（前版曾寫 3 天，無出處，已更正。）
- 「🟢 資料日在規則內」／「資料日在規則內只表示…不是買賣訊號」：出自 `docs/vnext/NEWUI2_DATA_FRESHNESS_FIRST_SCREEN_DESIGN_2026-11-18.md`（使用者 2026-11-18 核准方案 C，**僅限 🗂 資料新鮮度總覽**）。「只表示…」句逐字重用；🟢 chip 字樣為 PROPOSED。
- 未來資料日＝紅 Unavailable：Issue #1202 現行行為（見上）。

## 最小正式接線差額與 Gate（⛔ 皆未授權）
差額：查詢服務（代碼→標的資訊 VM）、真實資料源、六欄 FieldVM 填值、查無／錯誤分類、session 隔離。≤3 Gate：
1. **真資料權利／PIT／Schema**：來源授權、資料日（PIT）規則與 Schema 契約。AI 總管推薦：先核准這一項，理由：沒有授權與 PIT 規則，後兩項的查詢服務與接線都無資料可接（推薦只是建議，不是批准）。
2. **查詢服務契約**：輸入正規化、查無／來源失敗／日期不可信的分類與字樣核准。AI 總管推薦：第 1 項核准後再核准，理由：分類與字樣要依真實來源的失敗型態定稿（推薦只是建議，不是批准）。
3. **OneBrain 接線**：與六欄語意、位階（市場環境）一致性。AI 總管推薦：最後處理，理由：六欄語意與口徑要等前兩項定案才不會返工（推薦只是建議，不是批准）。

## Visual Gate 需裁示點
- (a) 🟢「資料日在規則內」chip 與現行契約 `ALLOWED_STATUS_PREFIXES["ok"]=()`（OK 態不外露狀態字樣）相抵觸；正式化前需裁示是否保留。
- (b) 🟡「部分欄位未取得」「N／6 欄有值」為新字句，需核准或改寫。
- (c) 9004 與 9005 皆為紅色，靠 chip 與內文文字區分；若要以色彩區分，需回 #1202 現行行為另議。

## 示範限制（邊角）
- 輸入「9100」等 4 位數字（非 9001~9099）會顯示「示範原型不查真實代碼」，這是示範限制。
- 全形數字（如「９００１」）不被視為代碼，會回「請輸入代碼（名稱搜尋尚未提供）」。
