## 二、來源差異與不可繞過的契約

`src/services/macro_v2_service.py::get_twii_ohlc(n_trading_days)` 目前以 parquet 讀 xs/open/high/low/close，但**不帶 is_stale/as_of/upstream_state**；`src/services/market_twii_view_service.py::get_twii_trend_view(n)` 帶新鮮度等事實但**只提供 close**；`src/services/ui2/real_feed.py` 目前只准已列 G2F 白名單的 `get_twii_trend_view`，卡片 `TWII_CARD_DAYS=1` 有既有測試釘住。

**資料契約候選（施工前須驗證）：**
- 日期 x 唯一升序、無未來日、不得把盤中未完成 K 棒作已收盤；每根 `open/high/low/close` 必須有限、正值且 `low <= min(open,close) <= max(open,close) <= high`。
- 來源、更新／觀測日期、is_stale、upstream_state、as_of 需與卡片一致；讀取資料與 freshness 要同快照／可追溯，不能把分開呼叫的不同版本假裝一致；`fetched_at` 是抓取時間，**不是歷史 PIT 可得時間證據**。
- stale、failed、missing、partial 都需要明確的不同狀態；不以 0、灰色正常線或假的 K 棒補缺。過期不等於 fresh；尚未評估不等於安全。
- HTML 在 #1097 的 FAKE 資料標示必須保留作為視覺預覽；正式 Real 路徑嚴禁合成值。成交量已有 NaN，不畫量、不把缺量當零；MA 與其他疊加線未核准。
- 不得逕 import `macro_v2_service` 至 `real_feed`，不得未審改 `G2F_IMPORT_ALLOWLIST`；如果加性 schema 不能安全滿足契約，應停在 Design Gate，不要為綠燈放寬守衛。

## 七、2026-11-26 MF1：客戶採方案 B，Streamlit 1.56.0 方向鍵穿到導覽認列為「已知平台限制」（append-only；第一～六節原文一字未改）

**授權／來源**：#1283 非作者 QA 回報 MF1（#1199 留言 7192593347）；根因與備選見 #1199 留言 7192913294；客戶裁示採**方案 B**（方案文字見 #1199 留言 7193549716，授權編號 AUTH-B-r01）。本節不改任何 `src/**`、`requirements.txt`、workflow 或守衛，只更新驗收（量測器）與文件。

### 已知限制（Streamlit 1.56.0）
- **現象**：在市場頁聚焦「期間」radio 後按方向鍵，焦點／選取會穿到頂部導覽。
- **根因（DOM 證據，非推測）**：1.56.0 的 radio `<input>` `name` 皆為空字串（導覽 5 個、期間 2 個）。Chromium 將同一 DOM 樹內空 `name` 的 radio 視為同一個隱含群組、依 DOM 順序環繞（導覽 5 個 → 期間 2 個）。診斷驗證：在 1.56.0 真頁面暫時把期間 radio 的 `name` 設為唯一值後即不再穿出；純 HTML 對照（兩組空 name vs. 兩組不同 name）重現同一行為。1.59.x 各 radiogroup 的 `name` 皆為唯一值，無此現象。`name` 由前端元件決定，`st.radio` 無對應參數；`st.form` 在 1.56.0 為 `DIV`（無 form owner），不能隔離。
- **重現表（真 Chromium；390／1280／1440 三尺寸結果相同）**：

| 操作 | 1.56.0 | 1.59.2 |
|---|---|---|
| 20 日 + ←（ArrowLeft） | 跳到導覽「🗂 資料」頁 | 留在市場頁，環繞到 60 |
| 20 日 + ↑（ArrowUp） | 同上，跳資料頁 | 環繞到 60 |
| 20 日 + →／↓ | 60 日（正常） | 60 日 |
| 60 日 + →（ArrowRight） | **焦點跳到導覽「📊 市場」**（值仍 60） | 環繞到 20 |
| 60 日 + ↓（ArrowDown） | 同上，焦點跳導覽「市場」 | 環繞到 20 |
| 60 日 + ←／↑ | 20 日（正常） | 20 日 |

- **影響範圍**：僅鍵盤方向鍵。滑鼠／觸控點選 20／60 的路徑已實測正常（切換、同源、根數）；方向鍵以外的輔助技術（螢幕閱讀器的瀏覽模式切換等）**未逐項實測，屬推論**。

### 驗收分流規則（量測器 `tests/ui2_viewport/measure_viewport.py`；以量測時**實際載入**的 `streamlit.__version__` 判，不靠旗標字串）
| Streamlit | 方向鍵檢查（20／60 × ←→↑↓，共 8 案例，每個案例後回市場頁並還原 20） |
|---|---|
| ≥1.59 且 <1.60 | **必過**：不離市場頁、期間 radio 仍在、焦點仍在期間 radiogroup、導覽選中項不變、值只在 20↔60 環繞；失敗＝該市場列 pass=False |
| 1.56.x（1.57／1.58 尚未驗證，同樣處理） | **不判失敗但必須如實記錄** `arrow_leak`（observed、各鍵結果、實測 radio `name` 清單、根因說明）；缺記錄或記錄與實測不符＝失敗；若實測不洩漏則如實記 observed=false，不假裝 |
| <1.56 或 ≥1.60 或無法解析 | 判失敗（宣告範圍外） |
- 記錄位置：四份 DEC-137 JSON 市場列的 `kbar_period60.arrow_keys`（含 `policy`、8 個 `cases`；1.56 檔另含 `arrow_leak`）。
