- 五頁主導覽可**在自身容器內**水平捲動；**整個頁面不得水平溢出**。焦點／方向鍵／Tab 到最後一頁時需可視；當前頁不只用顏色區分；導航控制需可觸控、可讀，採至少 44px 點擊目標作候選驗收。
- 新殼不得疊出第二個底部或抽屜主導覽；現行 JS_V4／鍵盤／focus／inert 守衛**先保留**，只有等價替代瀏覽器/安全測試通過才能在施工批退役，不能直接刪測試求綠。
- Sheet 選擇器、帳號若未通過正式 Auth/Sheet Gate，不顯示真實個人資料、不讀 FAKE/query/session 當登入、不開啟寫入；使用**既有正式 Capability 字樣**揭露未接線，不能把預覽功能偽裝成已上線。
- 📊首屏已核准「結論／市場狀態／Risk Cap／是否需行動／下一步／主 CTA」資訊不能被新導航擠出；既有 ≥160px 首屏／安全區量測須保留對等守衛，若新兩列造成不足就回到設計 Gate。

## D. 五頁責任分配（先不擴充 source 或公式）

| 頁 | 首屏必要資訊與可操作入口 | 下方 Primary／完整 Evidence 責任 |
|---|---|---|
| 📊市場 | 台股/國際趨勢、風險與需否行動（僅正式結果）、更新今日戰情 | 台股 Primary 與國際 mini；EPS×PE 只留有來源的研究情境，缺合法序列不得畫假圖 |
| 🎯標的 | 市場精選／查一檔雙模式、名稱或代碼搜尋、基本面先行摘要 | 已准許候選和財報/籌碼/產業證據；缺資料不得補 0 或推薦 |
| 💼持股 | 組合狀態／資料日／需處理單行，未登入明示不可判定 | 持股與 ETF 曝險分層、產業集中度 Primary、持股表；不得把空槽當已接 Auth |
| 👤我的 | 真實帳號/Sheet 狀態入口與設定 | 權限、設定，僅保留「資料頁」跳轉，不重建全來源健康度牆 |
| 🗂資料 | 來源健康總覽（能力與資料狀態分軸）、失敗／過期／未接線 | 完整來源清單、as_of／最近成功與最近嘗試、脫敏失敗原因、受影響頁；不將失敗視為市場風險或正式動作 |

完整計算與正反證在 canonical/Evidence→Digest，不從可視 Top-N 回推；OneBrain 依已准資料與 token/coverage Gate 才能啟用。新頁數不自動新增 API。
